FILES
index.html    Website HTML
style.css     Black/gold design, mobile layout, animations
script.js     Navigation, particles, scroll effects
portrait.webp Final polished portrait with gold halo

RUN ON WINDOWS / VS CODE
1. Extract the ZIP file.
2. Open the extracted Kishore_Final_Luxury_Portfolio folder in VS Code.
3. Open index.html using the Live Server extension or double-click index.html.
4. Internet is only needed to load the optional Google web fonts; the core site works offline.

REPLACE OLD SITE
1. Back up your old portfolio folder first.
2. Copy all four site files into that folder, replacing index.html, style.css, and script.js.
3. Keep portrait.webp in the SAME folder as index.html.
4. Hard refresh in your browser (Ctrl+Shift+R).

BEFORE PUBLISHING
- Add a real resume PDF and edit the resume button link (if desired).
- Add project source/demo URLs after you have published them.
- Check your visible contact details in index.html.
- The portrait is AI-stylized from your photo, not an unmodified camera photograph.
